# Codex Examples

Example prompts for using `stellar-agent` safely from Codex live in `prompts/`.

- `build-testnet-demo.md` initializes Testnet state and runs offline smoke checks.
- `run-smoke-test.md` submits a live Testnet XLM smoke payment and summarizes receipt metadata.
- `run-issued-asset-scenario.md` runs the issued-asset trustline and payment scenario.
- `run-claimable-balance-demo.md` creates, lists, and claims a Testnet claimable balance.
- `run-contract-smoke.md` checks Stellar CLI contract support and runs a Testnet asset-contract smoke path.
- `add-x402-demo.md` runs the local x402 Testnet HTTP payment demo.
- `run-mpp-demo.md` runs local one-time and session-budget MPP demos.
